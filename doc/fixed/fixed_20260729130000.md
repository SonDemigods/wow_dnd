## 已修复问题

### P1-6. Boss 召唤小怪 fire-and-forget 异步 IIFE 导致重复召唤风险
- **涉及文件**：[useBossMechanics.ts](file:///d:/openSource/wow_dnd/src/modules/combat/composables/useBossMechanics.ts#L153-L195)
- **修复方案**：在进入异步 IIFE 之前同步清零 `e.pendingSummons`，移除 finally 块中的异步清零，避免异步执行期间下一回合重复召唤。

### P1-7. usePlayerAction 中变量名遮蔽外层参数 ctx
- **涉及文件**：[usePlayerAction.ts](file:///d:/openSource/wow_dnd/src/modules/combat/composables/usePlayerAction.ts#L65-L79)
- **修复方案**：将 `applyDebuffToEnemy` 内的局部变量 `ctx` 重命名为 `effectCtx`，避免遮蔽 `usePlayerAction` 参数中的 `ctx: ICombatContext`。

### P1-8. EffectContext.baseStats.speed 始终硬编码为 0
- **涉及文件**：[useCombatLog.ts](file:///d:/openSource/wow_dnd/src/modules/combat/composables/useCombatLog.ts#L47-L83)
- **修复方案**：`createPlayerEffectContext` 中 speed 改为 `ctx.character.effectiveStats.dex || 0`；`createEnemyEffectContext` 中 speed 改为 `enemy.stats?.dex ?? 0`，与 useInitiative 先攻计算速度来源一致。

### P1-9. evaluateCondition 条件解析只支持 hp，其他属性静默返回 0 导致误判
- **涉及文件**：[usePassiveSkills.ts](file:///d:/openSource/wow_dnd/src/modules/combat/composables/usePassiveSkills.ts#L274-L298)
- **修复方案**：扩展支持 `mp` 属性条件判断；未知 stat 显式返回 false，避免基于初始值 0 误判。

### P1-10. combat/db.ts deleteCombatLogs 逐条删除效率低下
- **涉及文件**：[combat/db.ts](file:///d:/openSource/wow_dnd/src/modules/combat/db.ts#L104-L110)
- **修复方案**：替换为 Dexie 批量删除 API `where('combatId').equals(combatId).delete()`，避免循环逐条删除中途失败导致部分删除。

### P1-11. forms/store.ts 中 receiveHeal 未 await
- **涉及文件**：[forms/store.ts](file:///d:/openSource/wow_dnd/src/modules/combat/forms/store.ts#L109-L126)
- **修复方案**：将 `switchTo` 改为 async 函数，await `receiveHeal` 并添加 try-catch，避免 unhandled promise rejection。

### P1-12. pets/store.ts 使用 ref 存储函数引用
- **涉及文件**：[pets/store.ts](file:///d:/openSource/wow_dnd/src/modules/combat/pets/store.ts#L8-L48)
- **修复方案**：`logCallback` 从 `ref` 改为 `shallowRef`，避免不必要的响应式追踪。

### P1-13. useEnemyAction 中减伤计算未保护负数边界
- **涉及文件**：[useEnemyAction.ts](file:///d:/openSource/wow_dnd/src/modules/combat/composables/useEnemyAction.ts#L95-L99)
- **修复方案**：添加 `Math.max(0, ...)` 保护，防止 `damageReduction > 1` 时 finalDamage 变负数导致"回血"。

### P1-14. useItem 未校验 levelRequirement
- **涉及文件**：[inventory/store.ts](file:///d:/openSource/wow_dnd/src/modules/inventory/store.ts#L374-L377)
- **修复方案**：在 `useItem` 中添加等级校验，低等级角色不可使用高等级消耗品。

### P1-15. 任务物品可被丢弃和出售
- **涉及文件**：[inventory/store.ts](file:///d:/openSource/wow_dnd/src/modules/inventory/store.ts#L458-L460)（dropItemByIndex）、[inventory/store.ts](file:///d:/openSource/wow_dnd/src/modules/inventory/store.ts#L506-L513)（dropItemsByIndices）、[shop/store.ts](file:///d:/openSource/wow_dnd/src/modules/shop/store.ts#L520-L521)（sellItem）
- **修复方案**：三个函数中增加 `itemTemplate.type === 'quest'` 的拦截，返回 false，防止任务物品被误丢弃或出售导致任务卡死/存档损坏。

### P1-16. fromStorageFormat 丢失 createdTime
- **涉及文件**：[character/db.ts](file:///d:/openSource/wow_dnd/src/modules/character/db.ts#L175-L193)
- **修复方案**：在 `fromStorageFormat` 返回对象中添加 `createdTime: storage.createdTime`，避免重新加载角色时被 `Date.now()` 覆盖。同时修复了 `maxMana` 字段名映射错误（`storage.maxMana` → `storage.maxMp`）。

### P1-17. equipment/store.ts 异步操作无错误处理
- **涉及文件**：[equipment/store.ts](file:///d:/openSource/wow_dnd/src/modules/equipment/store.ts#L647-L667)
- **修复方案**：`addEquipmentTemplate` 和 `removeEquipmentTemplate` 添加 `.catch` 错误处理，失败时回滚内存缓存并记录日志。

### P1-18. getSkillTemplatesByClass 漏查通用技能
- **涉及文件**：[skill/db.ts](file:///d:/openSource/wow_dnd/src/modules/skill/db.ts#L241-L250)
- **修复方案**：改用 `toArray() + filter` 方式查询，返回职业专属技能 + classRestriction 为 null/undefined 的通用技能。原 `anyOf(classId, null)` 在 IndexedDB 中不支持 null 值查询会抛 DataError。

### P1-19. castSkill 未校验角色是否已加载
- **涉及文件**：[skill/store.ts](file:///d:/openSource/wow_dnd/src/modules/skill/store.ts#L367-L375)、[skill/store.ts](file:///d:/openSource/wow_dnd/src/modules/skill/store.ts#L621-L624)
- **修复方案**：在 `castSkill` 和 `canUseSkill` 中添加 `if (!charData) return false` 检查，避免无角色时仍触发 SKILL_CAST 事件。

### P1-20. saveSkillTemplate 中 classRestriction 使用 `|| null` 吞掉空字符串
- **涉及文件**：[skill/db.ts](file:///d:/openSource/wow_dnd/src/modules/skill/db.ts#L154)
- **修复方案**：改为 `classRestriction ?? null`。

### P1-21. selectCharacter 在新角色加载后才 emit LOGOUT 事件
- **涉及文件**：[character/store.ts](file:///d:/openSource/wow_dnd/src/modules/character/store.ts#L196-L227)
- **修复方案**：将 emit LOGOUT 移到更新 store 状态之前，确保监听器收到事件时 `currentCharacterId` 仍为旧角色 ID，正确清理旧角色资源。

### P1-22. setName 不刷新 characterList
- **涉及文件**：[character/store.ts](file:///d:/openSource/wow_dnd/src/modules/character/store.ts#L413-L414)

### P1-23. computeResurrection 在 maxHp 极低时复活为 0 HP
- **涉及文件**：[character/service.ts](file:///d:/openSource/wow_dnd/src/modules/character/service.ts#L265-L274)
- **修复方案**：改为 `Math.max(1, Math.floor(...))`，确保复活后至少 1 HP，避免立即死亡形成无限循环。
