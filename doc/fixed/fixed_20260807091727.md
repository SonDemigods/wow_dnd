## 修复内容

将 skill/store.ts、inventory/store.ts、equipment/store.ts 三个 800+ 行的单文件 Store 拆分为 composable 模式，参照 combat 模块的 store.ts(~170行) + composables/ 拆分模式。

### 拆分模式

每个 Store 统一执行：
1. **useXxxState** — 状态持有者（所有 ref/computed + persist + 初始化 + 查询 + 模板管理）
2. **useXxxYyy** — 动作 composable（接收 state，返回动作对象）
3. **store.ts** — 薄组合入口（~65 行），创建 state → 创建 composables → 返回扁平 API
