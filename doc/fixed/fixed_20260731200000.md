### P3-102：equipSkill 允许装备未学习技能

**涉及文件**：[src/modules/skill/store.ts](file:///d:/openSource/wow_dnd/src/modules/skill/store.ts#L488-L526)

**审计结论**：

代码注释（第 491-492 行）已明确设计意图：
> "如果技能尚未学习（不在 `skills` 列表中），会自动添加到列表后装备。"

实现逻辑（第 514-517 行）：
```typescript
// 如果技能不在已学列表中，添加进去（支持从模板直接装备）
if (!skills.value.some(s => s.id === skillId)) {
  skills.value.push({ ...skill });
}
```

**设计意图**：equipSkill 采用"装备即学习"语义，允许从模板直接装备技能。这不是 bug，而是明确的设计决策：
1. 等级不足时仍会被拦截（第 510-512 行：`skill.unlockLevel > characterStore.level` 检查）
2. 技能不存在时返回 false（第 506 行）
3. 槽位无效时返回 false（第 499-501 行）

**状态**：设计保留，代码注释已文档化，无需修复。
