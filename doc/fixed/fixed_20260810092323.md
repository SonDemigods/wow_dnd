## P1 严重（5 项）

### P5-001 法力恢复技能施放后不结束回合，战斗回合卡死
- **文件**: `src/modules/skill/composables/useSkillCasting.ts` + `src/modules/combat/composables/usePlayerSkill.ts`
- **修复**: useSkillCasting 的 mana_restore 分支新增 `heal = damageValue` 使 result.heal 有值；usePlayerSkill 的 heal 分支检测 `isManaRestore` 时跳过 `receiveHeal`（MP 已在 castSkill 中恢复），仅记录日志并结束回合。
- **回退说明**: 原方案使用独立 mana_restore 分支发送 `{amount:0, healType:'mana'}`，但与既有测试（healType:'health'）冲突。改为复用 heal 分支。

### P5-002 checkCompletion 使用 OR 逻辑与注释 AND 语义冲突
- **文件**: `src/modules/exploration/store.ts`
- **修复**: `||` → `&&`，修正为所有格子已探索且 Boss 被击败才标记完成。

### P5-003 多选项事件自动应用第一项，绕过用户选择
- **文件**: `src/composables/useGameActions.ts` + `src/components/GameMain.vue` + 新建 `src/components/popup/MultiOptionEventPopup.vue`
- **修复**: 新增 `showMultiOptionEvent`/`currentMultiOptionEvent` 响应式状态与 `MultiOptionEventPopup` 组件；`handleMultiOptionEvent` 不再自动应用 choices[0]，改为弹出选项界面供玩家选择；选择后调用 `handleEventChoice` → `applyEventChoice`。

### P5-004 移动端触摸点击格子无法触发探索交互
- **文件**: `src/components/ExplorationView.vue`
- **修复**: onTouchEnd 复制 endDrag 的点击判定逻辑（记录 touchStartTarget，未拖动时通过 `closest('.cell')` 找格子并调用 `handleCellClick`）。

### P5-005 属性药剂无 attribute_potion 能力时永久污染 bonusStats
- **回退**: 测试和 config 确认这是既有设计（带 attribute_potion 走 applyPotionBonus，不带走 applyBonus），dragon_breath_chili 等物品依赖此行为。回退为原始 `applyBonus` 路径 + DEV warn。不作为修复项。
