## P3-149（玩法·P2）：任务类型仅 kill/collect，目标类型枚举封闭

### 问题

`QuestType = 'kill' | 'collect'` 未扩展，任务玩法单一，全部是"杀 N 只怪"，缺乏 explore 等叙事多样性。

### 修复内容

**类型扩展**（`src/modules/quest/types.ts`）：
- `QuestType` 扩展为 `'kill' | 'collect' | 'explore'`
- `QuestObjective.locationId` 字段从"预留未使用"改为 explore 任务可选区域过滤

**纯函数扩展**（`src/modules/quest/service.ts`）：
- `checkQuestProgress` 的 `relevantData` 新增 `explored?: boolean; locationId?: string`
- 匹配逻辑新增 explore 分支：`explored === true` 时触发，`locationId` 为空则任意区域计数，否则仅匹配指定区域
- `getDefaultQuests` 补 1 个 explore 示例任务（`quest_explore_forest`）

**UI 文本生成**（`src/modules/quest/objective_utils.ts`）：
- `getObjectiveText` 新增 explore 分支：无 locationId → `探索{N}格区域`；有 locationId → `探索{locationId}区域`

**Store action**（`src/modules/quest/store.ts`）：
- 新增 `onCellExplored(locationId?: string)` action：遍历 in_progress 任务，调用 `_processQuestProgress` 传入 `{ explored: true, locationId }`
- `_processQuestProgress` 的 `relevantData` 类型同步扩展

**探索触发源**（`src/modules/exploration/store.ts`）：
- `revealGrid` 路径 3（treasure/trap/event/rest）：`isFirstVisit` 时调用 `useQuestStore().onCellExplored(currentAreaId)`
- `onBattleResult` 胜利/失败分支：`!cell.explored` 时调用 `useQuestStore().onCellExplored(currentAreaId)`
- 新增 `import { useQuestStore } from '@/modules/quest'`（无循环依赖：quest 不 import exploration）

**UI 图标映射**：
- `QuestPopup.vue`：`explore: { name: 'compass', gradient: 'nature' }`
- `QuestBoardPopup.vue`：`explore: 'compass'`

### 测试

- `test/quest/service.test.ts`：新增 10 项 explore 匹配测试（explored=true 计数、locationId 过滤、混合目标、纯函数不变性、进度上限、完成判定等）
- `test/quest/objective_utils.test.ts`：新增 3 项 explore 文本测试；修复防御性回退测试（原用 'explore' 当未知类型，改为 'nonexistent_type'）
- `test/quest/store.test.ts`：新增 6 项 onCellExplored 测试（部分进度、locationId 过滤、完成发奖、忽略非 in_progress、空 Map 安全）
- `test/exploration/store.test.ts`：补 mock `useQuestStore`；修复 onBattleResult 异步测试（emit 后加微任务刷新）
