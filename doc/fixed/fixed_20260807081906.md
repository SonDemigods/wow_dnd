## 修复内容

### P3-164：skill ↔ combat 模块间类型循环依赖

**问题**：`skill/types.ts` 导入 `EffectType` from `@/modules/combat/effects`，`combat/combatContext.ts` 导入 `Skill/SkillUseResult` from `@/modules/skill`，形成模块层面双向类型依赖。

**修复方案**：将 `EffectType` 提取到独立的无依赖文件 `combat/effects/effect-type.ts`，消除 skill → combat 的类型依赖方向。

**改动文件**：

| 文件 | 改动 |
|------|------|
| `src/modules/combat/effects/effect-type.ts` | **新增**：`EffectType` 联合类型独立定义，无任何 import |
| `src/modules/combat/effects/types.ts` | 改为从 `./effect-type` 导入 + re-export `EffectType` |
| `src/modules/combat/effects/index.ts` | 保持从 `./types` 统一导出（间接含 `EffectType`） |
| `src/modules/skill/types.ts` | import 路径从 `@/modules/combat/effects` 改为 `@/modules/combat/effects/effect-type` |
| `src/composables/useSkillDisplay.ts` | 同上 |
| `src/data/validate.ts` | 同上 |

**验证结果**：
- `tsc --noEmit --skipLibCheck`：0 错误
