## 修复内容

将 skill/log/map/quest/equipment/inventory 6 个 Store 的 `currentCharacterId` 从本地 `ref` 改为 `computed(() => gameStore.currentCharacterId)` 只读代理，与 exploration Store 已验证的 P3-153 模式一致。

### 改动模式

每个 Store 统一执行以下改动：
1. 新增 `import { useGameStore } from '@/modules/game'`
2. `const currentCharacterId = ref<string | null>(null)` → `const gameStore = useGameStore(); const currentCharacterId = computed<string | null>(() => gameStore.currentCharacterId)`
3. `initialize()` 中移除 `currentCharacterId.value = characterId`（由 GameStore 在 init 前设置）
4. `reset()` 中移除 `currentCharacterId.value = null`（由 `gameStore.setCurrentCharacterId(null)` 统一管理）
