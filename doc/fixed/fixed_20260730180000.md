### QA-7：console.ts 拆分（1277 行 → framework + commands）

- **目标结构**：
  ```
  src/modules/console/
  ├── index.ts              # 公共 API：exec / initConsole / registerCommand 等
  ├── framework.ts          # exec / initConsole / registerCommand / 命令注册表 / 类型定义
  └── commands/
      ├── character.ts      # gold / heal / levelup / stats 等
      ├── inventory.ts      # additem / removeitem / items 等
      ├── combat.ts         # spawn / kill / flee / combat 等
      ├── quest.ts          # quest / completequest 等（合并到 exploration_skill_quest）
      ├── skill.ts          # skill / learn 等（合并到 exploration_skill_quest）
      ├── exploration.ts    # goto / reveal 等（合并到 exploration_skill_quest）
      ├── system.ts         # help / save / load / export / import 等
      └── index.ts          # 汇总注册所有命令
  ```
- **拆分原则**：
  - framework 仅暴露 `registerCommand`、`exec`、`initConsole`、`CommandResult` 接口、`CommandCategory` 类型
  - 每个命令子模块导出 `registerXxxCommands(registry: CommandRegistry): void`
  - 命令注册统一使用 lowercase key（项目硬约束），方法调用仍用原 camelCase
  - 原 `modules/console.ts` 改为 re-export `./console` 入口，外部引用零感知
- **公共 API 兼容**：`window.cmd` 上的命令名（camelCase）与方法签名不变

### QA-6：audio/service.ts 拆分（1483 行 → service + effectChains + synth）

- **目标结构**：
  ```
  src/modules/audio/
  ├── index.ts              # 公共 API 不变
  ├── service.ts            # AudioService 类：生命周期 / 事件监听 / 公共 API（≤ 520 行）
  ├── effectChains.ts       # 效果链构建（reverb/chorus/phaser/shimmer 连接图）
  ├── synth/
  │   ├── sfxSynth.ts       # SFX 合成分发表（SfxType → synth 方法）
  │   └── bgmSynth.ts       # BGM 管风琴合成（封装 OrganVoice 调度）
  ├── organVoice.ts         # 既有管风琴音色
  ├── store.ts / db.ts / types.ts  # 既有模块
  ```
- **拆分原则**：
  - `AudioService` 保留为对外单例入口，内部委托给 `sfxSynth` / `bgmSynth` / `effectChains`
  - 效果链节点从类字段迁移到 `effectChains.ts` 的工厂函数 `createAudioNodes()`
  - SFX 合成的 switch-case 表迁移到 `sfxSynth.ts`
  - BGM 场景切换迁移到 `bgmSynth.ts`
  - 事件监听（eventBus 订阅 GameEvents）保留在 service.ts
