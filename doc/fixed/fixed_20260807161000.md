## 问题描述

**编号**：P3-162
**分类**：玩法·P2
**状态**：已修复

### 问题
AI 决策类型仅 3 种（basic_attack / skill / heal），缺乏 buff/summon/defend。

### 核实结果（2026-08-07）
- `AiDecision = basic_attack | skill | heal`，仍 3 种决策类型。

### 影响
敌人不会主动施放 buff/debuff；4 种 AI 策略实际只在 3 种决策间调概率，差异感不强。

---

## 修复内容

### 1. 扩展决策类型与战斗上下文
- `AiDecision` 新增 `{ type: 'buff'; skillId }` 和 `{ type: 'defend' }`。
- `BattleContext` 新增 `enemyHasBuff` / `playerHasDebuff` 字段，策略可感知已有 buff/debuff 状态，避免重复施放。

### 2. 新增 4 个怪物技能
| skillId | 名称 | type | 效果 |
|---------|------|------|------|
| war_cry | 战吼 | buff | attack_up+20 (3 回合) |
| fear_roar | 恐惧咆哮 | debuff | attack_down-15 (3 回合) |
| stone_skin | 石化皮肤 | buff | defense_up+15 + shield+20 (3 回合) |
| weaken | 虚弱术 | debuff | vulnerable+15 (3 回合) |

### 3. 更新 10 个 Boss skillPool
为 10 个 Boss 追加新 buff/debuff 技能（war_cry / fear_roar / stone_skin / weaken），确保 AI 的新决策有技能可用。

### 4. 重写 4 种策略决策逻辑
决策维度从"仅敌人 HP"扩展为"敌人 HP + 玩家 HP + 回合数 + 已有 buff 状态"：

| 策略 | 特点 |
|------|------|
| **aggressive** | 猛攻至上：开场（回合 1-2）buff 增强，玩家残血（<25%）必攻击终结，常规 50% 技能/10% buff |
| **defensive** | 稳扎稳打：三级 HP 分层（≥60% buff+defend / 40-60% defend / <40% 治疗），防御优先 |
| **balanced** | 攻守兼备：高血混合 buff/defend/攻击，玩家残血补刀，低血治疗 |
| **boss_phase** | 分阶段升级：正常开场 buff，半血混合 buff/治疗/攻击，狂暴（<20%）全力攻击 |

### 5. 新增实战执行路径
- `case 'buff'`：复用 useSkill 的 isBuff 逻辑，区分自身增益（enemyEffects）与对玩家减益（playerEffects）。
- `case 'defend'`：非技能防御行为，不消耗技能冷却，施加临时 `defense_up`（DEFEND_DEFENSE_BONUS=10，持续 DEFEND_DURATION_TURNS=2 回合）。
- `CombatActionType` 新增 `'defend'`；`CombatEventType` 新增 `'combat_defend'`。

### 6. 新增 11 个配置常量
AGGRESSIVE_BUFF_CHANCE / DEFENSIVE_BUFF_CHANCE / DEFENSIVE_DEFEND_HP_THRESHOLD / DEFENSIVE_DEFEND_CHANCE / DEFENSIVE_DEFEND_CHANCE_LOW_HP / BALANCED_BUFF_CHANCE / BALANCED_DEFEND_CHANCE / BOSS_BUFF_CHANCE / BOSS_HALF_BUFF_CHANCE / DEFEND_DEFENSE_BONUS / DEFEND_DURATION_TURNS。
